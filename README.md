This is a beginner-level data science machine learning project for college, which predicts the house price based on certain factors.
Multiple Linear Regression is used, the model is trained on total of 10 most contributing features.
Streamlit is used to develop the frontend, it is still not deployed, will do so in the future.
The website allows user to select the colony, area, no. of bathrooms and all the other important factors.
It is just for practice and can be expanded further in the future.

The dataset was taken from Kaggle, cleaning of data was done to remove NaN values and convert the object to numerical for machine learning purpose.
Streamlit website can also generate the report of the predicted price with all the features user selected.
The report can also be imported in the csv format.
